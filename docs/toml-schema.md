# TOML Схема

## Блок `[main]`
`name` определяет имя раскладки.
`short_name` используется как короткий идентификатор.

## Блок `[msklc]`
Нужен для корректной генерации раскладок для Windows.
В нём указываются поля, которые будут отображаться в системных
настройках, в инсталляторе/деинсталляторе, а также в system-tray.

## Блок `[ligatures]`

В этом блоке можно определить **лигатуры** — когда при нажатии одной клавиши
вводится сразу несколько символов (от 2 до 4). Это удобно для ввода каких-нибудь
сочетаний вроде `=>`, `->`, ` - ` и т.д.

> [!IMPORTANT]
> Лигатуры **не поддерживаются** в Linux и будут заменены на пустую клавишу!

> [!WARNING]
> Для Windows, лигатуры в слоях `caps` и `caps_shift` не поддерживаются системой.

**Определение**:
```toml
[ligatures]
FatArr = "=>"
ThinArr = "->"
```

**Использование**:
```
@FatArr @ThinArr
```

## Сетка клавиш

Сетка клавиш стандартной 104-105-клавишной клавиатуры вписана в 5×10:

```
1     2     3     4     5     6     7     8     9     0
Q     W     E     R     T     Y     U     I     O     P
A     S     D     F     G     H     J     K     L     ;
Z     X     C     V     B     N     M     ,     .     /
Space ~     -     =     [     ]     \     '     ISO_\ Num_.
```

Это покрывает все символьные клавиши, которые можно переопределить
в системах Windows, Linux и macOS. F-* и Control-клавиши не обрабатываются.

> [!NOTE]
> Зачем переопределять пробел? Он же и в Африке пробел...
>
> На пробел в некоторых случаях можно назначить символ **неразрывного пробела**.
> Он выглядит как обычный пробел, однако «склеивает» между собой слова.
> Полезно его ставить, если вы не любите висячие предлоги, союзы и т.д.
>
> Символ неразрывного пробела определён как `@Nbsp`.

> [!NOTE]
> Чтобы обозначить клавишу как пустую, используйте `@None`.

> [!NOTE]
> В сетку клавиш можно вписывать любые ASCII и Unicode символы.
> Однако, поддерживаются только коды с максимальным диапазоном в 0xFFFF.
> Для эмодзи и других символов вне этого диапазона используйте лигатуры.

## Слои

Системные раскладки поддерживают следующие слои:

| Слой        | Описание                                                  |
| ----------- | --------------------------------------------------------- |
| base        | Базовый слой, в котором по-умолчанию находится клавиатура |
| base_shift  | Слой, который актвивруется зажатием только клавиши Shift  |
| altgr       | Слой, который активируется зажатием только клавиши AltGr  |
| altgr_shift | Слой, который активируется зажатием AltGr + Shift         |
| caps        | Слой включается при однократном нажатии CapsLock          |
| caps_shift  | Слой включается при нахождении в CapsLock-слое + Shift    |

> [!NOTE]
> Также, в системных раскладках есть слой, который активируется при зажатии Ctrl/Cmd,
> однако, для совместимости с программами очень **не рекомендуется** его изменять.
>
> Поэтому, в данной утилите ctrl и ctrl_shift слои намеренно **не поддерживаются**.

> [!NOTE]
> В стандартных системных раскладках слои `caps` и `caps_shift` полностью совпадают
> со слоями `base_shift` и `base` соответственно (но только для буквенных клавиш).
>
> С помощью задания `caps` и `caps_shift` слоёв можно реализовать виртуальное
> переключение раскладки, например между EN и RU символами (см. пример Universal-Layout)
